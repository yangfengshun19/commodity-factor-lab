# 本阶段结论与交付说明

2026-11-01 · 历史阶段本地收尾版；延展研究未完结，尚未发布 GitHub。权威交付：原项目 v0.17 代码与本文档。本文依据原结果、已有实收评审和 Codex 核对整理；后续研究副本不自动成为发布版本。

研究问题是：注册仓单和期限结构能否在价格动量之外提供增量预测信息？在上期所 2020–2025 年逐合约历史、2023–2025 年评估段上，**仓单有正向线索，但尚未确认有效；没有确认的可交易 Alpha。** 历史已被反复查看，不能称为独立确认样本。

本项目先审查七类26个旧指标，再对具备输入条件的主要候选开展增量检验。除了仓单与期限结构，还实际考察相对基差、规范化持仓变化与工业品参考信息；动量为主要基准，真实现货基差因输入不合格而未开展新增预测检验。旧“价值”指标归入动量，波动指标定位为风险用途。不能将本项目说成只做仓单，也不能将26个旧指标说成全部完成独立有效性检验。具体角色与完整结果见[因子覆盖表](FACTORS.md)，汇总摘要见[研究摘要](ABSTRACT.md)。
