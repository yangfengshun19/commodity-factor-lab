# 对外介绍

本项目复核商品期货原有七类26个指标，修正定义与旧结论，基于交易所逐合约数据检验期限结构、仓单、相对基差及持仓变化在动量之外的增量信息，并比较工业品参考信息。已检验候选均未形成稳健确认；仓单有正向线索，但同时区间含零、多重检验后未通过。工程侧提供离线合成演示、逐日资金账与独立核对，尚无确认因子或可交易 Alpha。公开包不含行情，真实结果需本机冻结输入复算。

可以通俗地说：我们检查了一套期货指标，纠正了重复、误命名和证据不充分的问题，重建主要候选并用真实历史检验，还做出了能运行、能对账的研究工具。目前有一些值得继续研究的线索，但没有足够证据确认它们能稳定赚钱。

26是旧指标数，不是26个独立因子全部完成验证；来源不足的真实现货基差未进入新增预测检验。研究依照声明的回溯时点假设，尚未认证历史初发版本。原论文样本使用史无法完全核实，登记不涵盖未知历史搜索。新市场扩样、E经济价值协议与前向采集均未实施，不计入本阶段已完成结果。
