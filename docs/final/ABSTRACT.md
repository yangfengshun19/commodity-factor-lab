# 研究摘要

本研究对商品期货原有七类、26 个指标开展定义与证据复核，将重复价格指标合并、错误命名修正，并撤出当前缺乏稳定构造或复现依据的指标。在此基础上，利用上海期货交易所 2020–2025 年逐合约历史数据，以 2023–2025 年为评估段，在价格动量基准之外检验期限结构 carry、基差动量、注册仓单季节稀缺度、相对基差及规范化持仓变化的增量预测信息，并比较工业品参考价格信息的预测表现。研究采用同合约收益标签、截面部分秩相关、HAC 推断和 BY 多重检验校正；不同研究的样本与控制口径分别披露。

共同样本包括 674 个有效评分日，每日覆盖 8–9 个品种。仓单稀缺度的平均部分秩相关为 0.1050，但三项同时 95% 近似区间为 [−0.0117, 0.2218]，计入 20 项已知探索后的 BY q≈0.751，尚不足以确认有效性。carry、基差动量、相对基差及规范化持仓变化未形成稳健增量证据；加入工业品参考价格信息后的整体预测误差相对期货信息基准增加约 1.89%。真实现货基差受发布时间、实物匹配和截面覆盖限制，未进入新增预测检验。

工程侧构建逐合约、整数手数、换月双腿收费、保证金占用与逐日结算的模拟资金账，并保留容量约束下的延迟、残仓和失败路径。固定单边总摩擦 5bp、保证金 20%、假设按记录开盘价全量成交的主情景中，动量组合三年累计模拟收益为 23.02%，动量与 carry 各半秩分数混合为 10.09%，该固定混合方式未改善累计表现。

研究未确认可交易 Alpha，亦不据未检出关系断言全部经济机制无效。现有证据来自已查看的上期所历史，历史首发数据版本、真实成交与跨市场外推尚未认证；原论文所称 2016–2023 年区间的实际用途无法核实，已知探索登记不覆盖未知历史搜索。主要交付为可追溯的多类因子复核、完整的负结果与不确定性报告，以及可运行、可对账的研究工程。公开源码提供合成演示，真实数据复算仍需本机冻结输入。

关键词：商品期货；因子复核；增量预测；注册仓单；期限结构；多重检验；可复现研究。
