## 本地交付物

在项目根目录运行 `python scripts/package_public.py` 生成 `dist/commodity-factor-lab-github.zip`。解压后的 `commodity-factor-lab/` 才是预定 GitHub 源码目录；不要直接上传包含本机数据和运行产物的整个工作目录。

`python -m build --sdist --no-isolation` 可生成 `dist/commodity_factor_lab-0.17.0.tar.gz` 安装源包，需要先安装开发依赖。GitHub 源码 ZIP 包含 CI 配置和允许分发的历史脚本等附加内容，两个包的文件数不同属于预定范围差异。
