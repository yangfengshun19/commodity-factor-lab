# 同合约 Top20 榜单持仓研究

版本范围：本页记录 v0.6 的“每条历史记录各自截止”基线。v0.7 保留此版，并新增“窗口记录在当前信号截止前已知”的信息集比较，规则与边界见[历史版本复核](vintage_review.md)。

冻结协议为 `configs/position_study.toml`。本轮只激活原来因来源不足而不可检验的持仓候选，不更换原十品种、信号日选约、未来标签或因子方向。原未就绪记录保留；本次激活计为新增一次探索，共十三项已登记项，仍不能覆盖全部旧研究搜索，也不构成独立样本发现。

## 信号到底是什么

每个合约每日独立将完整前二十名持买单量相加、完整前二十名持卖单量相加，再作差，得到榜单净持仓 `N`。多头和空头名单各自排序，可能不是相同会员集合；会员榜单还会进出。此量不等于全市场净持仓、固定一批投资者的增减仓，也不是商业套保者的 COT 分类。会员替客户持仓，经纪会员身份不直接揭示客户的交易动机。

信号为 `(N(c,t) − N(c,t−20)) / OI(c,t)`，其中两端必须是 **同一真实合约 c**，分母为该合约当日单边总持仓。原信号日选中的近月合约在过去没有被选中，也仍须读取该合约自身的过去排名，不能接上上一张主力合约。

二十日窗口与正方向沿用此前候选定义。该公式是可反驳的榜单持仓假设，不预设净多增加一定带来上涨，也不代表已经得到收益证据。

## 固定准入规则

- 日历来自冻结十品种研究的观测交易日期：2022-12-05 至 2025-12-31，共 747 日；前二十日仅用于 2023 年首个评价日的预热。
- 逐日官方原响应校验报告日期和来源哈希，解析实际合约，排除品种汇总、总计及期权。双方均需名次 1–20 恰好出现一次、会员数字编号各自唯一、持仓为非负整数；无披露或不完整都不补零。
- 每条原始记录的更新时间须在该历史日既定 20:30 本地截止之前。晚发和未知时钟保持缺失；当前可下载文件仍不能完整认证历史初发版本。
- 每个合约每日总持仓须为正整数，各侧 Top20 合计不得超过单边总持仓。该约束能发现一些口径错误，但不是完整的历史版本认证。
- 严格要求窗口内连续二十一个交易日全部合格；中间缺失也使窗口不可用。这比只检查两端更保守，可能减少覆盖。本轮不会根据结果改成两端规则或降低最少品种数。
- 只有完成所有计划日期的尝试后才启动完整诊断。请求失败被保留；公开接口访问限制或连续三日失败会停止采集，不能被误记为完成。

## 检验及解释

控制 126 日动量、carry 和 252 日基差动量；逐日最少八品种进行截面秩残差相关。标签沿用冻结信号日所选合约从下一交易日结算至再后二十交易日结算的变化。HAC 四十日，至少 252 个有效日期才给出近似 p 值，否则只报告覆盖、均值和不可推断原因。

所有旧探索记录连同本次激活共同报告 BY 校正；未就绪项仍占名额。不根据覆盖或收益重选原选约，不能把缺失的商品解释成没有持仓变化。预测关系也不等于按结算价成交的收益、因果影响或投资 Alpha。

独立对账模块不调用生产解析与滚动因子函数，直接对原 JSON 排名重新求和，按完整交易日历重算同合约信号；另使用已保存单日官方导出检查年包总持仓。检查次数是相关的程序核对次数，不是独立统计样本。

## 本机复核命令

```bash
# 网络采集；成功原响应不覆盖，断点续采跳过已登记日期
cfl fetch-positions --config configs/position_study.toml

# 完成全部日期尝试后，运行来源准入及固定诊断
cfl position-research --config configs/position_study.toml
```

此配置引用本机已保存的行情、标签和前次探索哈希；公开源码包不包含真实数据，不能直接把这些命令当成不需数据的演示。无数据演示仍使用 `cfl contract-demo`。

官方[日周数据](https://www.shfe.com.cn/reports/tradedata/)与[排名披露标准](https://www.shfe.com.cn/reports/tradedata/dailyandweeklydata/dailyranking/decl/202401/t20240117_331641.html)用于核查来源和字段。现行披露门槛不能自动回填历史；本轮依据每份原响应是否真实披露、是否完整来判断。
