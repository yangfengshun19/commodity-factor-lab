# 共同样本、效应大小与分辨率 · v0.17

主要问题固定为：在相同可观测品种与日期上，carry、基差动量、季节仓单稀缺，在原定价格控制之外的平均部分秩相关有多大，误差范围有多宽？本轮使用已看过的历史进行探索性证据复核，不新增策略、改变信号或寻找最优窗口。

## 样本与估计对象

沿用十品种、2023—2025、原曲线/仓单信号和下一交易日结算至再后20交易日结算的固定同合约标签。carry控制126日动量；基差动量和仓单控制动量与carry。控制结构保留，三个系数不被当作同一含义的因子排行榜。

每日期货动量、carry、基差动量、仓单均有限的品种形成共同输入资格。标签有限另形成共同测量样本，缺标签不填、不用于过去选约或交易。至少8品种才计算；若任何一个候选的秩回归退化，该日三个候选共同留缺失。所有候选使用相同品种和有效日期。黄金无仓单，因而共同研究范围可能少于原价格研究，不能冒充原十品种完整样本。

先分别对截面秩信号、秩标签关于原定秩控制残差化，再算残差相关。估计对象是有效日期的等权平均相关，不是池化品种回归、因果效应、可交易收益或预测模型的样本外表现。另按年、品种和状态报告资格，防止共同样本掩盖覆盖损失。

## 主要不确定性评价

完整原交易日历上的40日Bartlett HAC作为主要估计；保留缺失时隙，以0估计得分处理缺失，使用n/(n−1)修正。至少252个有效日期，渐近正态近似。保留20日和80日滞后的全部敏感性结果，不能从中选择较窄区间或较小p值。

每个候选报告均值、HAC标准误、双侧近似p值、点态95%区间。另以z(1−0.05/(2×3))给出本轮三项Bonferroni同时区间。后者仍取决于HAC近似是否适用；原历史已被选择、早期全部搜索未登记，不能称为全探索历史的95%覆盖保证。

先重算原不同样本诊断，逐项复现原均值、有效日数、t与p，再另生成共同样本结果；原文件保持。新增三个共同样本问题计入探索登记17→20，旧17项原字段保留及逐字节另存，另算保守的20项BY列。重复使用历史并不被此操作消除，不据q值授予投资资格。

## 分辨率与“小效应”

固定±0.05部分秩相关为本轮统计分辨率目标。这是明确的研究设计尺度，**不是公认盈利门槛，也不换算成年化收益**，且是在已看历史之后声明。只有本轮同时区间完全位于该带内，才描述为“在该近似和尺度下可约束为小效应”；区间较宽时保留未决，不能凭p>0.05宣布无效。严格的实际等效性结论仍需合适设计和独立证据。

给出固定SE下的正态位置模型规划诊断：用本轮三项双侧Bonferroni临界值，求正向真实相关δ满足双侧拒绝概率80%的最小δ，概率为1−Φ(zcrit−δ/SE)+Φ(−zcrit−δ/SE)。这是估计方差下的规划分辨率，不是把观察t值代入得到的事后功效，不证明未来样本功效，也不按该诊断承诺所需年数。不能跨越相关的理论取值范围寻找实际不可能的可检测效应。

未来经济价值检验必须使用可执行组合、事前风险预算、实际约束和费用后差额。秩相关区间无法代替这一步。下一阶段的收益门槛与风险规则须另固定后再运行，不能据本次结果调整。

## 方法核查及限制

- [statsmodels官方HAC文档](https://www.statsmodels.org/dev/generated/statsmodels.stats.sandwich_covariance.cov_hac.html)：假定连续等间距时间序列。本项目按交易时隙保留间距，并未把小样本、非平稳或缺失机制问题自动解决。读取文档的假设与参数。
- [statsmodels多重检验原实现](https://www.statsmodels.org/stable/_modules/statsmodels/stats/multitest.html)：核对Bonferroni及BY算法。有效边际推断仍是校正的前提。
- [statsmodels等效性说明](https://www.statsmodels.org/stable/generated/statsmodels.stats.weightstats.ttost_ind.html)：等效性需要预先界定的区间，未拒绝零效应不等于等效。本项目不直接套用其独立样本t检验，也不声称本轮实现了该TOST程序。
