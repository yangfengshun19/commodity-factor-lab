# 原始记录对账与覆盖扩样 v0.4 · 2026-10-29

本轮先独立核对构造，再按事先写下的数据覆盖规则扩样，未改变三个候选的公式、方向、预测期限或控制变量。结果是：核对范围内未发现生产计算差异；扩样后仓单关系更值得跟进，但仍不足以确认有效性。

## 1. 独立对账

对原六品种基线完成 91,750 项程序检查，最终 0 项差异。它们包括全期 8,730 个日期/品种上的选约、carry、相对基差、同合约收益链、126 日动量和 252 日基差动量；21 个预先指定案例日期的 1,470 条年包合约记录；另取五日的 350 条官方日行情；1,806 组仓单明细之和、唯一总计、单位和发布时间，以及 126 组季节分位案例。

独立实现没有调用生产曲线、基本面或原始数据解析器。累计收益通过对数求和复核生产滚动乘积，元数据从原 JSON 重读并逐合约按发布时间选择，仓单从仓库明细加总复核唯一总计。年度与日度行情均来自同一交易所，不能称为独立数据供应商核验；程序检查数量也不等于独立市场样本数。

独立对账器初版曾产生 145 个差异。追查发现原年包同表混排期货与期权，对账器没有在期权标识处结束前一个期货身份，误覆盖了最后一份期货合约的记录。修正对账器、增加期权区块回归测试并保留首次输出后，第二次全部一致。生产解析已正确隔离期权，没有修改原行情、因子或旧结论来消除这些差异。

对账不认证历史版本未修订，也不认证经济机制有效。信息截止假设、月度参数粒度、费用和实际成交条件仍保留原限制。仓库与厂库须分开；交易所的[标准仓单平台通知](https://otc.shfe.com.cn/news/notice/304.html)也分别列示两种类型，不能把不同口径不加说明地合并。

## 2. 扩样依据与范围

分析前将十八个上期所候选、案例日期、来源抽查和筛选规则记录在 `configs/validation_plan.json`。规则是最早观测不晚于 2020-01-02，且 2022 年共同价格特征可用比例至少 80%；筛选过程不读取评估期未来收益。这里“最早观测”不是已经逐一认证的上市日期。

最终保留铜、铝、锌、螺纹钢、热卷、天然橡胶、石油沥青、纸浆、黄金、白银十品种，2020–2025 年共 169,562 行。铅、镍、锡、燃料油、不锈钢和线材因完整特征历史比例不足，氧化铝与丁二烯橡胶因样本起点后才出现而排除；所有排除记录保留。完整窗口门槛会排除某些压力期或较薄市场，可能限制代表性，不能据此判断这些品种的经济价值。

原六品种的特征值在扩样面板中逐项保持一致，结果变化来自研究范围变化。黄金在本次仓单接口中没有相应记录，保持缺失，不补零；白银只有 282 个成功周观察，其余八个有仓单的保留品种各 301 条。H3 在有效截面实际使用八至九品种，价格候选九至十品种。仍只有上期所和以金属为主的样本，不包括农产品或完整中国商品市场。
