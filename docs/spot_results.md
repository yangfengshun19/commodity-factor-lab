# 真实现货准入 · v0.8 · 2026-10-29

**官方报价可以取得，但还不能作为合格的现货基差因子进入现有截面研究。** 本轮完成来源、日期、单位、成交状态和原选期货的匹配检查；没有计算新增 IC、p 值或投资收益。已登记探索族保持十四项，主候选仍为三项，所有投资主张资格保持 false。

## 固定的小样本

`configs/spot_readiness.toml` 在本机采样前固定十二日期，包括 2020 年、2023 年末、新旧接口边界、2024 年春节休市与复市、年中/年末、2025 年黄金税收公告实施前后。`configs/spot_sources.toml` 记录发现的真实页面地址，没有猜测文章编号或逐页爬取历史列表。

来源浏览时已经见过少量报价，本计划只固定数据准入采样，不能称为未看数据的统计预注册或独立验证样本。两种黄金报价不是两个独立品种。

| 现货合约 | 对应期货品种 | 十二日期中的成交有效日 | 十一交易日中的缺口 |
|---|---|---:|---|
| Au99.95 | 黄金 au | 11 | 本小样本没有缺口 |
| Au99.99 | 黄金 au | 11 | 本小样本没有缺口 |
| Ag99.99 | 白银 ag | 7 | 一日无此合约行，三日零成交 |

春节负对照 2024-02-12 为空表，三个合约均不造价格。白银 2023-12-29 在表内缺行；2024-06-28、2024-12-31、2025-06-30 零成交、价格缺失。原缺失不填充，也不用 Ag(T+D) 替代。

十八个固定公开请求全部 HTTP 200，包括十二行情页与六规格/制度页；十二行情表均通过结构及日期身份校验，形成二十九条价格诊断。HTTP 成功不代表历史可用性认证，小样本覆盖不能外推全年。

## 官方来源与口径

2024 年起使用交易所[每日行情查询](https://www.sge.com.cn/sjzx/quotation_daily_new?start_date=2024-01-30&end_date=2024-01-30)，要求每行日期与所请求日期完全相等。更早使用真实历史文章：[2020-01-02](https://www.sge.com.cn/sjzx/mrhqsj/5146750?top=789398439266459648)、[2023-12-29](https://www.sge.com.cn/sjzx/mrhqsj/10005759)，另核对正文标题日期。不能只凭 URL 日期认定表内数据身份。

上金所 [Au99.95](https://www.sge.com.cn/h5_cpfw/Au9995H5)、[Au99.99](https://www.sge.com.cn/h5_cpfw/Au9999H5) 为实盘黄金，报价单位都是人民币元/克。当前页面中的每手重量不能作为报价换算乘数，也不能反推所有历史交易单位。上期所[行情说明](https://www.shfe.com.cn/reports/tradedata/)列明黄金为元/克、白银为元/千克。因此本次价格比较单位乘数均为一，不能因黄金期货每手一千克再把报价乘一千。

上金所[2010 年白银上市公告](https://www.sge.com.cn/jjsnotice/505003)明确 Ag99.99 的人民币元/千克报价、实物交割及 T+2 安排。它不等于延期 Ag(T+D)，也不等于即时交割 T+0。上期所[白银产品页](https://www.shfe.com.cn/products/futures/metal/ferrousandpreciousmetal/ag_f/)原 HTML 内嵌合约文本可核对白银报价单位与牌号，但不是完整逐日历史参数档案；没有执行页面脚本。

[上期所黄金交割附件](https://www.shfe.com.cn/products/futures/metal/ferrousandpreciousmetal/au_f/appendix/202105/t20210521_797346.html)与上金所黄金牌号有部分重叠，但交割形态、品牌、仓库、金重和出入库规则仍需对应。该 URL 路径包含 202105，当前正文标注 2024-07-12；路径年份不能充当历史版本证明。相同最低成色不等于两所之间无成本互换的同一批实物。

[财政部、税务总局 2025 年第11号公告](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/zzs/202511/t478143.html)自 2025-11-01 起实施，适用时间取决于实物交割出库，并区分主体和用途。本轮只标记日历区间，未把报价日期当成出库日期，未按单一税率机械调整，也未由三个相邻日期推断政策效果。

AKShare 的[官方 SGE 适配源码](https://github.com/akfamily/akshare/blob/main/akshare/spot/spot_sge.py)还提供历史图表接口，但其返回数组顺序为日期、开、收、低、高，且不含充分的成交/初发证据。本轮直接使用有明确日期、OHLC 和成交量的官方表格，没有因接口名称含 spot 就把延期、国际板或基准定价全部并为现货。

## 为什么仍不检验预测效果

1. **历史发布未认证。** 当前网页只给行情日、交易时段或当前响应时钟；交易结束不等于发布，HTTP 修改时间和采集时间也不能倒填为当年已知。全部 `publisher_clock_verified=false`，未假设一天滞后。
2. **物理和税务匹配未完成。** 当前产品介绍不能认证逐日历史品牌、地点、税负及可交割转换。严格 `spot_basis` 仍全部缺失，不能把一个粗糙价格比改名为已匹配因子。
3. **截面只有两个品种。** 最低八品种门槛保持；重复黄金报价不能增加独立品种数。若改做贵金属时间序列，需要另立问题、控制与检验协议。
4. **标价时点不同。** 现货日收盘与期货日结算不是同一时点的买卖报价；白银还涉及 T+2。诊断值不是套利利润、便利收益、可成交价差或投资净值。

只对正成交量、正成交金额、有限正 OHLC 且高低关系合理的记录，计算 `log(现货收盘 / 原冻结选约结算)`。选约沿用十品种研究原表，按相同交易日精确连接，不能近邻补日、换成主连或按价差挑期货。所有严格因子观测及新增预测检验均为零。

## 可复现与后续决定

采样器仅做有界、限速、验证 TLS 的公开 HTTPS 读取；遇 403/429 或连续三次失败停止，不执行响应脚本、不复用账户。原 HTML、响应头、抓取起止及哈希只保存在本机，不随公开源码包分发。离线回放校验配置、源目录与原研究输入哈希：

```bash
python scripts/probe_spot_sources.py
python -m commodity_factor_lab spot-readiness
python scripts/reconcile_spot_probe.py --raw RAW_DIRECTORY --report REPORT_DIRECTORY --bars CONTRACT_BARS --output NEW_AUDIT_DIRECTORY
```

首次命令需要网络；第二个命令只读取已有原响应。公开克隆不含真实行情，不能直接复现本机的真实报告；单元测试使用人工构造的表格，可离线运行。独立对账程序另读原 HTML 和逐合约行情，不调用生产解析器或因子函数；检查计数不是独立统计样本数，也不能替代供应商认证。

**本轮决定：不批量扩采贵金属来凑截面，不激活现货基差。** 下一步优先验证工业品现货来源，要求有明确地区、牌号、税口径和可核查的历史发布证据；先做同样的小样本准入，再冻结扩采与新增区间检验。当前已检验候选未稳健确认的结论保持。
