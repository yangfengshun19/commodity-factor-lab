# 研究路线与验收条件 · v0.17

当前主问题：期限结构与注册仓单在价格动量之外是否有增量预测和经济价值？NBS参考价属于已有首轮诊断的旁支，暂不继续扩展。SQL、日更和看板暂缓。

| 顺序 | 工作 | 验收条件 |
|---|---|---|
| 1 | 修复失格持仓 | 已完成；退出、重新入池、受阻及先前拒绝换月有测试，原十品种路径不变 |
| 2 | 容量与未成交处理 | 首轮完成；过去量预算、分日执行、先平旧约、新信号替代、残仓和失败完整记录 |
| 3 | 收敛研究设计 | 预测主线已收敛；下一步固定交易经济价值协议、事前风险预算和费用后经济阈值 |
| 4 | 效应与不确定性 | 首轮完成；共同样本、HAC区间、时间敏感性和规划分辨率已报告，未恢复独立发现资格 |
| 5 | 独立样本 | 核查真正未用样本，否则前向采集；先固定协议，报告全部结果 |
| 6 | 公开复现和呈现 | 区分原冻结重放与新数据运行，统一结果页、来源说明、许可证与GitHub入口 |

第2项解决了程序如何面对容量不足，不代表真实成交认证。[本轮结果](capacity_results.md)显示1%有终端残仓，混合路径遇无成交日缺开盘而中止；5%仍有延迟。实际竞价量、信号与交易合约的映射、无开盘报价时的权益/资金预算尚需处理。

改用更活跃合约或新的缺价规则须登记新增探索，不在负结果上挑参数、删品种或翻符号。无需等完整历史初发和经纪账户档案才开展第3、4项，但各类主张要有相应证据。允许研究以完整验证的负结果结束，不承诺一定找到盈利因子。

历史细节保留在各版本结果和续接记录；当前任务以本页及[状态表](task_status.md)为准。

最新[共同样本结果](factor_evidence_results.md)统一674日；下一交付与停止条件见[研究决定](research_direction.md)。不再在同历史试窗、改方向或删行业追求显著。
