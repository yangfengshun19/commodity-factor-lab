# 工业品参考数据接入 · v0.9 · 2026-10-30

**已经找到并跑通值得扩采的官方工业品参考价格源。** 国家统计局的生产资料价格旬报提供具体产品、规格、统计期和正文发布时间，能补充原有期货、仓单与持仓研究。它属于全国流通环节的期间参考信息；精确交割现货基差需要另行匹配。本轮没有新增 IC、p 值或投资收益，十四项探索族保持。

## 实际完成的数据

`configs/nbs_readiness.toml` 在本机采样前固定八期公告、三份说明、原输入哈希与两个未发布期负对照。选源浏览已见过部分价格，这是准入采样固定，不是未看数据的统计预注册。

- 十一个固定公开请求全部成功，原 HTML、响应头、采样起止和哈希留存。
- 八期各五十种商品，共 **400条价格和400条规格记录**；记录数不能当作独立统计样本数。
- 原池中铜、铝、锌、螺纹钢、热卷、天然橡胶、纸浆七个品种有相关参考；排除旧口径后共53条，其中46条的公告事件落在原行情区间。
- 铅也有报价，但不在原十品种池中，没有为凑八品种临时加入。

主要来源为国家统计局[2024年1月下旬旬报及规格附表](https://www.stats.gov.cn/sj/zxfb/202402/t20240202_1947216.html)。这些经营企业批发、销售环节价格包含流通费用、利润和税费，不能统一当作某交割库、某品牌、某固定税率的可执行报价。

程序寻找第一个信号截止不早于公告时刻的已观察交易日；恰好相等可对齐，晚1纳秒进入下一截止。只导出公告事件检查，不把稀疏抽查填成完整日频历史。正文发布时钟是当前页面的明确声明，字段称 `source_declared_published_at`；历史初发版本认证仍为false，没有把抓取或HTTP修改时间冒充初发。

## 假日缺期和规格断点

[官方答复](https://www.stats.gov.cn/hd/lyzx/zxgk/202405/t20240524_1954120.html)确认2024年2月中旬因春节取消发布，下旬公告仍使用中旬调查数据计算变化。虽然可以事后推算中旬价格，推算资料当时未公开，不能填回当期信号。[2025年发布日程](https://www.stats.gov.cn/sj/fbrc/ljxxfb/202412/t20241230_1957931.html)还取消当年1月下旬、10月上旬。本轮两个负对照是2024年2月中旬及2025年1月下旬，均没有生成记录。一般每月4、14、24日的规律不能替代年度具体日程。

| 条目 | 差异 | 处理 |
|---|---|---|
| 螺纹钢 | 早期Φ16–25mm与后期Φ20mm | 早期不并入后期参考映射 |
| 热轧钢材 | 早期3mm普通薄板与后期普通板卷 | 产品形态不同，不拼接 |
| 纸浆 | 早期漂白化学浆与后期进口针叶浆 | 未证实同等级，旧口径不映射到sp |
| 调查范围 | 2020年样本24省，后期全国31省 | 范围进入可比序列身份 |
| 天然橡胶 | 2020年公告说明由人造板替换为SCRWF | 不由涨跌倒造更早橡胶历史 |

变更证据见[2020年公告及附注](https://www.stats.gov.cn/sj/zxfb/202302/t20230203_1900591.html)与后期规格表。当前仅抽查断点，尚未定位所有变更的准确生效期。可比身份包含产品规格、单位、调查范围和规格说明；规格或范围变化会分段。全国参考与期货交割的品牌、仓库、税负转换始终未获认证。

## 商业来源筛选

本轮发现的SMM[接口文档](https://data.smm.cn/dataapi/%E9%93%9C/cu_smm_bonded_copper_spot_price)列出必填OAuth token，[价格页面](https://www.smm.cn/)存在登录锁定；没有请求授权报价、开户或购买。

还需核对价格构造：SMM[山东铜报价调整公告](https://news.smm.cn/news/102528162)说明了2024年发布时段及期货盘面、升贴水组成；[2026年EQ铜新品公告](https://news.smm.cn/gonggao/104078690)也明确绝对价由盘面基准加升贴水形成。不能直接当成独立于期限结构的新信息，2026年新品也不能回填2020–2025年。后续来源登记须保留参考合约与采价窗口。

## 验证与复现

```bash
python -m commodity_factor_lab fetch-nbs-probe
python -m commodity_factor_lab nbs-readiness
python scripts/reconcile_nbs_probe.py --raw RAW_DIRECTORY --report REPORT_DIRECTORY --calendar SIGNAL_CALENDAR --output NEW_AUDIT_DIRECTORY
```

首个命令需网络，最多11个固定来源，响应上限3MB，间隔至少1秒；403/429或连续三次失败停止。后两个命令读取保存的原文。原行情不随源码包发布，公开克隆可运行人工表格测试与离线演示。

144项测试通过，覆盖重复去重、冲突拒绝、正文时钟、跨期/未来、精确截止、假日、闰月、规格/区域分段、负对照、非法数字、访问停止和故意错误价格。独立读取原HTML及CSV后，**2,060项检查零差异**；未调用生产解析或因子函数。独立读取器初版被跨标签脚注和CSV BOM打断，修正并加测试后完成；没有为通过核对而修改原始价格。检查次数不是统计样本数或独立供应商认证。

## 下一节点

优先固定完整期次清单、取消发布与规格变更，再扩采这套官方数据。随后另立“已发布工业品价格信息”的预测问题，先定频率、对照与检验再计算效果。现有八品种截面门槛不变，七个工业品参考不能直接启动旧截面实验；既有历史也不能追认为未知样本。严格交割现货基差继续单独准入。
