## 可复核的来源

年包入口为交易所[数据下载索引](https://www.shfe.cn/reports/tradedata/datadownload/download.json)，读取其中年度 ZIP 地址；`fetch-shfe` 保存原包、哈希和失败清单，`ingest-shfe` 解析 XLS/XLSX。只补 Excel 合并单元格的合约身份，不向下填价格。需要额外安装 `.[ingest]`。

合约参数例：[2024-01-30 合约资料](https://www.shfe.com.cn/data/busiparamdata/future/ContractBaseInfo20240130.dat)。旧结构逐行有更新时间，新结构使用顶层时钟；两者均存在时取较晚时间。原解析 51 次成功、21 次失败的目录保持不动，新建派生目录后达到 72 次解析成功。解析恢复不是历史时点认证。

仓单例：[2020-01-03 原 JSON](https://www.shfe.com.cn/data/tradedata/future/dailydata/20200103dailystock.dat)。每周取观测行情中当周最后一日，采集开始前固定全部日期。2025-11-21 起连续五次旧接口失败后停止，保留五个失败及最后两个未尝试日期；不伪称完整下载。来源后来将螺纹钢、热卷拆为仓库与厂库，当前只接续仓库序列，不把两者无说明相加。

## 日期不等于发布时间

[2025-11-21 新仓单 HTML](https://www.shfe.com.cn/data/tradedata/future/stockdata/dailystock_20251121/ZH/all.html)可读，报告只给日期；本次探查也未得到可用的 HTTP Last-Modified。它可作未定时参考，未接入严格发布时间输入。下一步需要可验证的发布日历、原始公告或明确登记为假设的保守滞后敏感性实验，不能伪造午夜时钟。

[2024-01-30 交易参数](https://www.shfe.com.cn/data/busiparamdata/future/ContractDailyTradeArgument20240130.dat)本次返回的 `update_date` 为 **2026-02-05 17:03:09**；[同日结算参数](https://www.shfe.com.cn/data/busiparamdata/future/Settlement20240130.dat)为 **2025-01-10 18:04:22**。这说明仅凭 URL 和 report_date，不能认定内容是 2024 年当时已知的版本；不据此断言所有数值都被修改，也不把它们当成可信的当日交易输入。原响应和本地校验哈希保存在探查目录，校验时间不冒充发布时间。
