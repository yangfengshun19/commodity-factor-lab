# 共同样本的效应与不确定性 · v0.17 · 2026-10-31

当前可以更明确地结论：仓单保留正向线索；期限结构和基差动量没有稳健正向增量证据；三个候选都不能被现有结果证明为小效应或无效。共同样本和区间评价完成后，仍没有确认的新因子或可交易Alpha。

## 同一批日期和品种

三个候选都使用674个有效日期，实际截面为8—9品种，黄金因无仓单而不参加，白银使用597日，其余八个品种各674日。2023/2024/2025有效日期分别220/238/216；不是674份独立市场状态。共同输入必须同时有动量、carry、基差动量和仓单，标签只在测量时要求可用，没有据未来标签修改过去选约或订单。

原不同样本的均值、有效日数、t与p全部复现；共同样本另算，不覆盖原结果。仓单的测量样本与原版相同，其均值和主标准误保持一致。carry和基差动量的均值有变化，来自样本变化而非公式调整。

## 样本能辨认多小的关系

固定±0.05为本轮统计分辨率目标，不是盈利门槛。三个主同时区间均没有完整落在该带内，因此都不能据此约束为“小到可忽略”。

在明确的固定估计误差、正态位置规划模型中，以本轮三项临界值达到80%拒绝概率所需的最小正效应，carry约0.1869、基差动量0.1786、仓单0.1578，显著大于0.05。这是条件于估计误差的诊断，不是实际未来功效，不承诺需要多少年。它说明：现有历史不适合对很小的效应作强结论。

## 验证与研究决定

独立脚本使用SciPy秩、statsmodels残差回归和HAC协方差、独立正态分位数及求根，重算共同资格、日相关、区间、分辨率与BY；19,036项核对、0差异。测试包含故意篡改日相关和区间的检出、缺日时隙、退化截面、候选缺失联动和规划诊断不依赖观察均值。工程核对数不是独立统计样本数。
