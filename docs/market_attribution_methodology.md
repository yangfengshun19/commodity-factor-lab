# 既有市场模拟的盈亏与风险拆解

这是v0.14固定实验的事后会计解释。已看过动量23.02%、混合10.09%的主结果，再固定本轮拆解范围；不称事前确认，不新建策略、不重跑权重、不挑品种或年份。旧16项探索登记保持，不新增p值或投资发现。配置与本说明在新拆解计算前另存回执。

## 固定输入与全量输出

只读原主情景：单边总摩擦5bp、保证金20%、假设记录开盘价全量成交，等权做多、动量、动量+carry三本已有账。源run.json、原始行情/曲线、目标审计表及12张逐日/持仓/交易/拒单表分别核验原哈希。不改原文件；所有原十品种、三年份均报告。

对每个交易日、每个品种按实际保存的手数拆解：

`毛盈亏 = 前一日手数×乘数×(今日开盘−前一日结算) + 今日手数×乘数×(今日结算−今日开盘)`

前一日及今日手数来自各合约的真实保存持仓，不能在换月日将两个合约的价差当收益；费用从实际成交腿记录汇总，并分别核对开仓/平仓手数。净盈亏为毛盈亏减费用。无持仓/成交的品种日贡献为0，表示账本没有敞口，不是对缺失行情填0；任何必要估值缺失即失败。

所有品种与年度贡献用初始1000万元作统一分母，直接相加应等于原累计收益及混合减动量差。它们是现金盈亏贡献，不是复利收益归因。另报告开仓、退出、同合约调整/反转、双腿换月、强制处置、终端清仓各类事件费用；换月与调整同时发生时归为换月，不声称识别“纯换月成本”。

## 风险、回撤与目标结构

- 逐日毛/净盈亏除初始资金形成可加序列，用样本标准差（ddof=1）×sqrt(252)作描述性年化波动率。它不同于以每日权益为分母的复利收益波动；不叫风险匹配后的Alpha。
- 品种方差贡献定义为`Cov(品种净盈亏/初始资金, 全组合净盈亏/初始资金)`；其和应等于组合方差。除以组合方差得到份额，份额可以为负；0方差时份额保持缺失。只描述本样本共同波动，不估计未来风险，也不证明因果套保机制。计算口径核对[NumPy cov](https://numpy.org/doc/stable/reference/generated/numpy.cov.html)与[std](https://numpy.org/doc/stable/reference/generated/numpy.std.html)官方文档。
- 从包含初始资金基点的原净权益路径找每本账自己的最大回撤峰/谷；逐品种净现金贡献在峰后至谷日相加，再除以该峰权益，应还原该账最大回撤。三本账可能是不同区间；不能把各自回撤贡献相减当成同一市场冲击下的因果效果。零回撤允许空窗口。
- 真实敞口描述采用保存的日末结算价名义金额，报告平均总绝对/净敞口与品种分布。未使用盘中最大敞口或认证实盘风险。
- 对已有146组调仓目标分别报告最大绝对权重、平方权重和、有效绝对持仓数量`(sum(abs(w)))²/sum(w²)`。这是目标结构描述，不拟合最优集中度。
- 同一品种/调仓日比较动量与混合目标的方向，完整报告同向、反向、仅一方非零、双零。重读当时曲线的动量/carry平均秩，报告两分数混合前绝对和与归一系数；不利用随后涨跌挑子集。
- “动量秩与carry秩各50%后再归一”不等于“两本资金组合各半”。分数相互抵消后，再归一到100%总绝对敞口，可能使少数方向一致品种的权重增加；本轮只解释已有目标是否出现该现象，不改成更好看的另一种策略。

## 允许的结论

可回答哪些品种、年份、毛盈亏与摩擦贡献了已观察到的差异，以及风险和目标集中程度如何变化。不能仅凭某品种贡献为负将其删除；不能把混合中某一现金贡献直接解释为独立carry因子的因果收益；不能用较小回撤宣称策略优越。当前来源、成交、保证金和费用的回溯假设全部继承[原模拟边界](market_benchmark_methodology.md)。

独立脚本用逐笔交易现金流恒等式重建品种净盈亏，以另一条路径核对上述持仓估值归因，并检验方差份额、回撤窗口和目标集中度。不导入生产归因模块。检查通过只说明算术一致，正式推断和前向样本仍是后续工作。
