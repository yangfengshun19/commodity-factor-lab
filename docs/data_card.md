# 历史数据卡

本卡依据本地原始快照及新流程的首次质量审计编制。统计对象是从原论文目录迁移的**逐品种因子 CSV**，不是合并面板。原文件未被改写；原论文与旧程序生成的结果在本地另存。

## 数据规模与覆盖

共 499 份逐品种快照，228,336 行，原 CSV 约 21.24 MB；同一品种在不同因子类别中重复出现，行数不能解释为独立市场观测数。默认研究区间为 2023-01-01 至 2025-10-10。

|---|---:|---:|---:|---|

“可用文件”表示完成读取且在研究日期内有记录，不表示所有因子完整或能够支持组合回测。各品种的上市日期、可用日期和缺失情况仍不同。32 份股指与国债快照默认排除；26 份价差快照因没有有效真实日期整体排除，其余 441 份进入商品研究面板。

## 已识别的问题

1. **26 份价差快照只有一条 1970-01-01 记录。** 多数对应郑商所品种，无法从现有文件恢复真实日期。保留文件并排除，不猜测年份，不用其他因子类别的价格补写价差数据。
2. **仓单样本很短。** 文件合计覆盖 2025 年 8 月至 10 月的局部日期；实际因子组合可用期更短。默认 60 天门槛下，仓单回测会标为短样本，不将其高年化数字当成稳定证据。
3. **持仓样本主要在 2023 年。** 默认 2025 年时间外区间无法检验这类因子。3 份文件的日期列名缺失，可由明确的 ISO 日期索引修复；原文件名中的 `filled` 表明数据曾经过填充，但具体方式未在现有材料中完整追溯。
4. **价格质量与交易日缺口。** 首次审计发现价差类有 636 行 OHLC 不合法，期现、趋势、价值、波动各有 4 行；另按各类数据的共同日期统计，在品种自身首尾日期内共发现 1,201 个缺失日期，同一日期可能在不同类别重复计数。持仓估值缺口会使相应组合回测无效，即使单个文件的非空价格看起来合格，也不代表组合可以回测。
5. **因子跨品种量纲不同。** 原始仓单量、价差绝对值、均线差和席位净持仓规模会受品种单位和价格水平影响；初始版本保留原指标作诊断，不能把截面排序自动解释为纯 Alpha。
6. **来源与时间戳不足。** 原代码显示行情和基础数据来自 AKShare 转接的新浪、东方财富及现货/持仓接口，但 CSV 未逐行记录抓取时间、发布时点或数据修订版本。额外一日发布滞后只是一项保守约定。
7. **连续价格的可交易性未核验。** 不同类别可能使用当日主力合约或接口连续合约，切换合约的收益可能混入换月跳点，尚需具体合约数据复核。

## 因子字典

| 类别 | 原指标 | 原实现含义 |
|---|---|---|
| 价差 | C_frontnext | 近月与次近月结算价差，按近月价和期限差缩放 |
| 价差 | C_mainsub | 持仓量主力与更远次合约之间的年化相对价差 |
| 价差 | C_nsnormal | Nelson–Siegel 对数价格曲线拟合中的曲率参数 |
| 仓单 | warrant_count | 原始仓单数量/库存字段，非同比增速；具体单位待核实 |
| 仓单 | W_pct, W_ratio | 约 50 日仓单滚动分位、当前量与滚动均值之比 |
| 期现 | fs_basis, fs_carry | 现货价减期货价、该差值除以期货价；carry 未按到期时间年化 |
| 期现 | fs_exmom | 期货日收益减现货日收益 |
| 趋势 | t_macross, t_mamom | 10/20 日均线比、60 日均线的 5 日差值 |
| 趋势 | t_maratio, t_mom | 价格/20 日均线、20 日累计收益 |
| 持仓 | pr_netmom_topN | 前 N 席位净多持仓变化，原程序先按自然日重采样再差分 240 日 |
| 持仓 | pr_lschgratio_topN | 前 N 席位多头增量/空头增量；分母为零时缺失 |
| 价值 | Val_halfyear, Val_oneyear | 126/252 交易日前价格到当前的收益，反转假设需另行指定负方向 |
| 波动 | vol_std | 20 日收盘对数收益标准差 |
| 波动 | vol_gk, vol_rs | 单日 OHLC 的 Garman–Klass / Rogers–Satchell 波动估计 |

新价格计算模块使用完整滚动窗口；旧快照曾使用部分窗口或扩展窗口，所以新算结果不保证逐项等于历史快照。没有针对现有快照倒推完整基本面原始数据。

## 复核与使用

运行 `cfl audit` 生成逐文件质量、各因子覆盖率与输入 SHA256；运行 `cfl run` 同时检查实际组合持仓的价格缺口。CSV 与毕业材料不随公开仓库分发，数据再分发授权待作者确认。合成演示独立存放，报告醒目标注其性质，不混入历史研究结果。

## v0.2 新增审计（2026-10-29）

上文统计仅描述迁移的旧文件。受控研究统一使用一个 trend 行情根目录，结束日为 2025-10-09，不把不同家族混为可交易行情。

跨家族审计发现价差类与规范趋势类共有 29,184 个可比较日期/品种键，其中 3,034 个键至少一个 OHLC 字段不同。其他家族在各自可比重叠范围未发现这一类价格冲突，不能据此证明它们的时间戳或连续构造正确。

新采集的新浪连续价格版本请求原池中的 68 个商品代码，67 个成功、RU 超时。每个成功品种保留响应、地址、时间与哈希。AP/CF 的 2024-01-30 缺口仍存在；EB 已有 2025-10-09 记录。版本审计中，研究区间的 41,823 个共有键 OHLC 均未变化；新版本多 EB 一个日期，缺 RU 全文件。更长的历史预热和少一个来源品种也会影响资格与组合，不能视为严格的单因素修复实验。不能把重新下载等同于获得正确的历史原貌。

这份新快照只截断至旧研究截止日，不是新增的独立时间外样本。连续价格缺少实际合约身份及换月认证，当前仍不能认证投资业绩。受控结果及失效项目见[研究重建](research_reset.md)。
