# 原论文代码归档

这里保存原研究采集、分析和数据库实验的源码，便于核对经济含义与数据处理历史。当前维护的程序位于 `src/commodity_factor_lab/`。

这些脚本使用当时的接口、路径、依赖和数据库环境，部分代码会在导入时立即下载数据、创建目录或连接数据库。因此请只阅读源码；需要复用时先把计算逻辑提取为纯函数，补齐时间线与输入验证后再接入当前流程。

归档中的明文数据库配置已替换为环境变量，禁用 TLS 证书验证的代码已移除。历史绝对路径和旧计算口径仍可在源码中看到，它们仅解释原结果，不属于当前可用入口。

历史程序曾依赖 AKShare、SciPy、statsmodels、SQLAlchemy、PyMySQL 和 requests。当前包不强制安装这些归档依赖，也不宣称旧采集接口在当前时间仍然可用。
