# 研究结果

- `runs/`：新框架每次运行自动生成的独立目录，包含 HTML、图表、CSV 和参数/输入哈希。
- `audits/`：价格版本差异审计，带输入哈希，不拼接或修复价格。
- `archive/`：从原项目迁移的分析汇总、图片和回归文本，仅作为原研究记录。

以上目录默认不纳入 Git。公开展示只使用 `docs/assets/` 中明确标记为合成数据的示例。新框架与旧脚本的权重、收益对齐和成本口径不同，指标不能直接互换。

`runs/study*` 是受控研究，`runs/demo` 与旧 `run` 为探索兼容层。`status=ok` 只表示计算完成，所有当前研究的 `claim_eligible` 均为 false。

当前主研究为 `runs/curve_pilot/` 的官方逐合约预测诊断；`runs/contract_demo/` 为全部合成的研究和现金账，二者不得混为市场投资业绩。每轮包含采集统计、完整假设、年度/留一品种诊断及失效标签。v0.3 方法见[逐合约方法](../docs/contract_methodology.md)。
